# Микросервис для скачивания файлов

Микросервис помогает работе основного сайта, сделанного на CMS и обслуживает
запросы на скачивание архивов с файлами. Микросервис не умеет ничего, кроме упаковки файлов
в архив. Закачиваются файлы на сервер через FTP или админку CMS.

Архив создается отдельным дочерним процессом `archive_worker.py` при запросе, не сохраняется на диске и передается клиенту потоково. В ответе браузер получает файл с именем `photos-{хеш}.zip`. Вложенные каталоги с файлами сохраняются внутри архива. Дочерний процесс останавливается при прерывании скачивания; ошибки архивации записываются в лог.

Каталоги архивов хранятся в `photos/<хеш>/`. Для локальных тестов, если каталога `photos` нет, используются каталоги из `test_photos/`.
Если каталога с запрошенным архивом нет, сервис возвращает статус 404 и сообщение «Архив не существует или был удален».
При отправке архива в терминале выводится отладочное сообщение `Sending archive chunk ...` для каждой порции данных.

### Проверка прерывания скачивания

Чтобы проверить обработку отключения клиента, задайте задержку перед каждой порцией архива и запустите сервер. В PowerShell:

```powershell
$env:ARCHIVE_CHUNK_DELAY = "0.2"
python server.py
```

Начните скачивание существующего архива и отмените его до завершения. Сервер должен продолжить работу без ошибки, связанной с разрывом соединения. Без переменной `ARCHIVE_CHUNK_DELAY` дополнительной задержки нет.

В Windows дочерний процесс можно найти командой:

```powershell
Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*archive_worker.py*' } | Select-Object ProcessId, CommandLine
```

Во время скачивания появится процесс `python.exe` с аргументом `archive_worker.py`; после отмены он должен исчезнуть. Для проверки ошибок временно добавьте в `archive_worker.py` исключение `IndexError` или `SystemExit`: процесс должен завершиться, а сервер — записать ошибку архивации.

### Проверка остановки сервера

Запустите скачивание большого архива и нажмите `Ctrl-C` в окне сервера. Сервер прекращает ожидание активных запросов не дольше чем за секунду, завершает дочерний процесс архиватора и дожидается закрытия его потоков через `communicate()`. Проверьте командой выше, что процесс `archive_worker.py` исчез.

От неавторизованного доступа архив защищен хешом в адресе ссылки на скачивание, например: `http://host.ru/archive/3bea29ccabbbf64bdebcc055319c5745/`. Хеш задается названием каталога с файлами, выглядит структура каталога так:

```
- photos
    - 3bea29ccabbbf64bdebcc055319c5745
      - 1.jpg
      - 2.jpg
      - 3.jpg
    - af1ad8c76fda2e48ea9aed2937e972ea
      - 1.jpg
      - 2.jpg
```


## Как установить

Для работы микросервиса нужен Python версии не ниже 3.6.

```bash
pip install -r requirements.txt
```

## Как запустить

```bash
python server.py
```

Настройки можно передавать аргументами командной строки или переменными окружения. Аргументы командной строки имеют приоритет:

```bash
python server.py --no-log --delay 0.2 --photos-dir "./photo-archives"
```

- `--log` / `--no-log` — включить или выключить логирование. Переменная окружения: `LOGGING=true` или `LOGGING=false`. По умолчанию логирование включено.
- `--delay` — задержка в секундах перед отправкой каждой порции архива. Переменная окружения: `ARCHIVE_CHUNK_DELAY`. По умолчанию `0` (без задержки).
- `--photos-dir` — путь к каталогу, внутри которого лежат каталоги архивов. Переменная окружения: `PHOTOS_DIR`. Если настройка не задана, используются `photos/`, а при его отсутствии — `test_photos/`.

Например, в PowerShell те же настройки можно задать через окружение:

```powershell
$env:LOGGING = "false"
$env:ARCHIVE_CHUNK_DELAY = "0.2"
$env:PHOTOS_DIR = "D:\photo-archives"
python server.py
```

Сервер запустится на порту 8080, чтобы проверить его работу перейдите в браузере на страницу [http://127.0.0.1:8080/](http://127.0.0.1:8080/).

## Как развернуть на сервере

```bash
python server.py
```

После этого перенаправить на микросервис запросы, начинающиеся с `/archive/`. Например:

```
GET http://host.ru/archive/3bea29ccabbbf64bdebcc055319c5745/
GET http://host.ru/archive/af1ad8c76fda2e48ea9aed2937e972ea/
```
